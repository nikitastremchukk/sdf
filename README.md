# Пошукове вікно

Проста програма на Python, що відкриває невелике вікно пошуку за комбінацією `Ctrl+Space`. У вікні можна ввести позивний або числовий ID.

## Запуск

1. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустіть програму:
   ```bash
   python search_app.py
   ```

Утримуйте програму запущеною у фоновому режимі. Натисніть `Ctrl+Space`, введіть позивний або ID, і результат з’явиться під полем введення. Якщо відповідності немає, відобразиться повідомлення "Нічого не знайдено".
